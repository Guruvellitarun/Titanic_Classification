## 🧠 Overview

This project explores the Titanic dataset to build predictive models that determine whether a passenger survived based on features like age, sex, class, and fare.  
We use machine learning techniques for training, tuning, and evaluating:

- ✅ Random Forest Classifier
- ✅ Gradient Boosting Classifier
- ✅ XGBoost Classifier

---

## 📁 Dataset

The dataset used is `tested.csv` (based on [Kaggle Titanic Dataset](https://www.kaggle.com/datasets/brendan45774/test-file)).  
Make sure it is in the project root directory before running the notebook.

---

## 🔍 Project Highlights

- 📊 Data preprocessing and label encoding
- ⚙️ Hyperparameter tuning with `GridSearchCV`
- ✅ Evaluation using Accuracy & Confusion Matrix
- 🌡️ Feature Importance ranking
- 🔥 Visuals: Heatmaps, Countplots
